Sync Steam save games between your PCs

A desktop app for Windows and Linux (Bazzite, SteamOS and others). It backs up and restores Steam save games to your own Google Drive, even when Steam runs in offline mode.

Download latest All releases
–GitHub stars –downloads –latest version

Runs on your PC

No server. The app reads your Steam folder and save files, zips them and sends them straight to your Drive.

Minimal access

Uses only the drive.file scope: the app sees the files it created and nothing else in your Drive.

No accidental overwrites

Compares content hashes, warns when the copy on this PC is newer than the cloud, snapshots before every restore and keeps the last 10 versions.

Windows ↔ Bazzite

Saves from Windows go into the right Proton prefix on Linux and back. Save locations come from Ludusavi's PCGamingWiki data (about 20,000 games).

How to use

  1. Install the app

    • Windows: download Checkpoint_x.y.z_x64-setup.exe and run it. Windows SmartScreen may warn because the app is not code-signed: click More info → Run anyway.
    • Bazzite / Linux: download the .AppImage, right-click → Properties → Permissions → allow executing (or chmod +x Checkpoint_*.AppImage), then open it in Desktop Mode.
    • On first launch, click Download manifest so the app knows where games keep their saves.

  2. Create a Google client ID (once, reused on every PC)

    See Connect Google Drive below. It takes about 5–10 minutes.

  3. Connect in the app

    • Open Settings → Backup location. If rclone is missing, click Install rclone: the app downloads the official build from downloads.rclone.org and verifies its SHA-256. No admin rights needed.
    • Paste the Client ID and Client secret, click Connect Google Drive and sign in in the browser window that opens.
    • Repeat on every PC with the same client ID and the same Google account.

  4. Day to day

    • Done playing on PC A: click Backup (or Back up all).
    • Before playing on PC B: click Restore (or Restore all).
    • Close the game first. The app blocks backup and restore while a game is running.

    The app's interface is currently in Vietnamese. The status names below show the English meaning.

    StatusMeaningWhat to do
    In syncThe save on this PC matches the latest cloud version.Nothing.
    Local is newerYou just played on this PC.Back up.
    Cloud is newerAnother PC backed up newer progress.Restore.
    ConflictBoth this PC and the cloud changed since the last sync.Open Restore, compare the dates and keep one. The other stays in history.

Connect Google Drive

Checkpoint talks to Google Drive through rclone. rclone's shared client ID is heavily rate limited by Google and is being retired, so you need your own client ID in Google Cloud. It is free and only you use it.

  1. Create a project

    • Open console.cloud.google.com/projectcreate and sign in with the Google account that will hold the backups.
    • Name it, for example checkpoint-rclone. Leave Organization as No organization. Click Create, then select the new project in the project picker at the top.

  2. Enable the Google Drive API

    • Open Google Drive API and click Enable.

  3. Set up the consent screen

    • Open Google Auth Platform and click Get started.
    • App name: Checkpoint. User support email and Contact email: your email. Audience: External. Accept the terms and click Create.
    • Under Branding, in App domain, fill in:
      Application home pagehttps://checkpoint.vercel.app/en Privacy policy linkhttps://checkpoint.vercel.app/privacy Terms of service linkhttps://checkpoint.vercel.app/terms Authorized domainscheckpoint.vercel.app
      Click a value to copy it. Leave the logo empty so you don't have to wait for Google to review it.
    • Under Audience, click Publish app → Confirm. The status must read In production.
      Don't leave it in “Testing”. In Testing mode a sign-in only lasts 7 days, after which backups stop working until you reconnect.
      No verification needed: drive.file is not a sensitive scope.

  4. Create an OAuth client

    • Open Clients → Create client.
    • Application type: Desktop app. Any name. Click Create.
    • Copy the Client ID (….apps.googleusercontent.com) and the Client secret (GOCSPX-…). Click Download JSON to keep a copy, because Google shows the secret only once.

  5. Paste into Checkpoint and sign in

    • In the app: Settings → Backup location, paste the Client ID and Client secret, click Connect Google Drive.
    • A Google sign-in page opens in your browser. Pick your account, then:
      If Google shows “Google hasn’t verified this app”, click Advanced → Go to Checkpoint (unsafe). It is your own app, so this is safe.
    • Click Continue to allow access to the files the app creates in your Drive.
    • If the browser then says “127.0.0.1 refused to connect”, ignore it. That address is rclone's temporary local server: it receives the sign-in code and shuts down right away, so any reload afterwards fails. Go back to the app and it shows as connected.

Troubleshooting

“Error 403: access_denied”
The app is still in Testing and the signed-in account is not a test user. Click Publish app as in step 3.
“redirect_uri_mismatch”
The client has the wrong type. Create a new client of type Desktop app, not Web application.
Backups stop working after 7 days
The app is in Testing. Publish it, then click Reconnect Google Drive in the app.
Another PC can't see my backups
Both PCs must use the same client ID and the same Google account. With drive.file, a different client ID can't see files created by another client.
Delete all data
Delete the Checkpoint folder in Google Drive and revoke access at myaccount.google.com/permissions.

Good to know

  • Saves tied to a SteamID: some games (Elden Ring, Sekiro, Dark Souls…) only load saves on the Steam account that created them. The app flags these games.
  • On Bazzite: run the game through Proton at least once before restoring a Windows backup, so Proton creates its prefix folder.
  • Snapshots: before every restore the current save is kept in %LOCALAPPDATA%\Checkpoint\snapshots (Linux: ~/.local/share/Checkpoint/snapshots).
  • Graphics settings files are not backed up by default, so a PC with a different GPU or screen doesn't get the wrong resolution. Turn this on in Settings if you want it.

Google user data

Checkpoint requests the Google Drive scope https://www.googleapis.com/auth/drive.file only to create, read and update the backup files it creates in a folder named Checkpoint in the user's own Google Drive. Data is transferred directly between the user's computer and Google. It is not sent to any server operated by the developer and is not shared with anyone. See the Privacy Policy.
