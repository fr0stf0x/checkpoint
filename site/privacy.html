Privacy Policy

Last updated: 7 November 2026

What Checkpoint is

Checkpoint is a desktop application that runs on the user's own computer. It backs up Steam save game files to the user's own Google Drive and restores them on the user's other computers. There is no Checkpoint server and no Checkpoint account.

Data the app accesses

  • Local files: the Steam installation folder (library list, installed game list, local account list in loginusers.vdf) and the save game files of installed games.
  • Google Drive: with the scope https://www.googleapis.com/auth/drive.file, the app creates and reads only the files it created itself, inside a folder named Checkpoint. It cannot see or change other files in the user's Drive.

How the data is used

  • Save files are compressed and uploaded to the user's Google Drive, and downloaded back when the user chooses to restore.
  • Each backup includes a small metadata file: game name and Steam App ID, device name chosen by the user, operating system, time of backup, file count, size and a content hash. Folder names in save paths may contain a Steam account ID.
  • This data is used only to show backup status and to perform backup and restore for the user.

Storage and sharing

  • Google OAuth tokens are stored only on the user's computer, in the configuration file of the rclone tool that the app uses to talk to Google Drive.
  • Backups are stored only in the user's own Google Drive.
  • No data is sent to the developer or to any third party other than Google. There is no analytics, advertising or tracking.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting your data

  • Delete the Checkpoint folder in Google Drive to remove all backups.
  • Revoke the app's access at myaccount.google.com/permissions.
  • Uninstall the app and remove its local folders (%APPDATA%\Checkpoint, %LOCALAPPDATA%\Checkpoint on Windows; ~/.config/Checkpoint, ~/.cache/Checkpoint, ~/.local/share/Checkpoint on Linux).

Contact

Questions about this policy: use the support email shown on the Google sign-in consent screen for Checkpoint.
